## Repository structure

- `frontend/` — React and Vite application
- `infra/` — AWS CDK application and backend handlers
- `docs/` — Architecture and project documentation

## Frontend development

```sh
cd frontend
npm install
npm run dev
```

## Infrastructure development

```sh
cd infra
npm install
npm run build
```
